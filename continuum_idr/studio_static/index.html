Methodological Boundaries & Limitations

  • Phone GNSS Update Rate: In IO-VNBD Driver E recordings, raw smartphone GNSS coordinates refresh at ~0.1 Hz (~9–10 second intervals). The engine only processes genuinely new fixes.
  • Target Drift Not Met: Consumer smartphone MEMS gyroscopes experience thermal drift that accumulates unconstrained over outages exceeding 40 seconds. Without map-matching or wheel odometry, the <10% drift target is currently missed.
  • Recorded Demonstration: This web interface connects to a local desktop Python SDK session processing recorded IO-VNBD sensors. It is NOT live phone hardware sensing.
  • No Arbitrary Baselines: Comparison baselines (frozen position, last speed) are only defined for standard fixed-interval benchmark windows, not manual interactive toggling.
